Instalar no iPhone

O Safari não oferece um botão de instalação automática como alguns navegadores. Siga estes passos:

1. Abra esta página no Safari.
2. Toque em Compartilhar (quadrado com seta para cima).
3. Escolha Adicionar à Tela de Início.
4. Confirme em Adicionar. Abra o ícone LOKI CINEMA na tela inicial.
